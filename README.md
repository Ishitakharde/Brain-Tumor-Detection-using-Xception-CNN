# Brain Tumor Detection Using Xception CNN

## Project Overview

This project focuses on developing a Deep Learning-based Brain Tumor Detection system using the Xception Convolutional Neural Network (CNN) architecture to classify brain MRI images into four categories: Glioma, Meningioma, Pituitary Tumor, and No Tumor.

The project applies Digital Image Processing and Deep Learning techniques to medical image classification. It involves image preprocessing, model development, training, validation, and performance evaluation.

## Internship

**Digital Signal Processing (DSP) Internship – IIT Bombay**

Developed as part of an internship project involving the application of deep learning techniques to medical image analysis.

## Objectives

- Develop an automated MRI image classification model.
- Apply transfer learning using the Xception architecture.
- Preprocess and normalize MRI images for model training.
- Evaluate model performance using accuracy, precision, recall, and F1-score.
- Visualize classification results using confusion matrices and performance graphs.

## Dataset Description

The dataset consists of brain MRI images categorized into four classes:

1. **Glioma** – MRI images containing glioma tumors.
2. **Meningioma** – MRI images containing meningioma tumors.
3. **No Tumor**
